# AK_bat — автотесты

Автотесты QA для проекта «Ак-Бата».

| Папка | Что внутри | Стек |
|---|---|---|
| [`web/`](web) | UI-тесты админки (145 тестов, 19 файлов) | Playwright (JavaScript), Page Object Model |
| [`mobile/`](mobile) | Тесты мобильного приложения | WebdriverIO + Appium (JavaScript), pytest (Python) |

Тесты запускаются только вручную (см. README в каждой папке). Автозапуска
и отправки отчётов нет. Логины и пароли берутся из переменных окружения
(`.env`, образец — `.env.example`) и в репозиторий не попадают.
